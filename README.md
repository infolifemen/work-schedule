# 📋 График выполнения работ

Веб-приложение для отслеживания статуса РП, писем и отчетов по объектам.

## Особенности

- 📊 Таблица со всеми работами (190+ записей, 49 объектов)
- 🔍 Поиск и фильтрация по объекту, виду услуг, статусу, исполнителю
- 🎯 Визуализация pipeline согласования (РП → Письма → Отчет)
- 📱 Адаптивный дизайн
- 🔒 Парольная защита
- 💾 Редактирование с сохранением в localStorage

## Стек

- **Frontend:** Next.js 14 + TypeScript + Tailwind CSS
- **Deploy:** GitHub Pages (статический экспорт)
- **CI/CD:** GitHub Actions

## Локальная разработка

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000)
